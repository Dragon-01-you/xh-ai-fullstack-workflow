# SPEC · 最小展示页
## 问题
小王需要别人能打开他的作品链接。
## 用户故事
- S1 作为访客，我打开首页能看到标题和表单。
- S2 作为访客，我提交后能看到结果。
## 验收
- [ ] S1 打开 /，看到标题和三个输入框；验证：手工：打开 / → 看到标题和三个输入框
- [ ] S2 提交有效数据，返回 200 并看到结果；验证：`node --test test/api.test.js`
- [ ] S3 缺字段提交，返回 400 并看到提示；验证：`node --test test/api.test.js`
## 不做什么
不做登录、支付、自动部署。
## 失败模式
输入错返回 400；数据库挂时页面提示暂不可用；重复提交允许。
## 前置条件
需要 Node 24 和本地端口；不需要域名和支付。
## 学习点
学会写验收和跑 TDD。

## 备注
本文档中的示例仅供团队参考；接口返回 <200> 时成功。
