# Phase 0 · 聚焦 / 问题证伪

> 目标：在写任何代码之前，先证明“这个问题值得解决”。**这一步禁止聊方案。**

## 要回答的六个问题（写进 `FOCUS.md`）

1. **谁**：具体到一个人（名字/角色），不是“用户”。
2. **现在怎么凑合**：没有你的东西时，他怎么解决？成本多大？
3. **可观察行为**：如果问题解决了，他会出现什么**能看见**的行为？
4. **最便宜的实验**：给 1 个人看一张图/一个假页面/发一条消息，成本多少？
5. **放弃信号**：出现什么信号，你就停掉这个项目？
6. **真实用户证据**：截图、聊天记录、waitlist、1 块钱付款——至少一样。

## 步骤

1. 填 `templates/FOCUS.md`，六问都要有答案。
2. 找到 1 个真实的人，做一次最便宜的实验（不是问卷）。
3. 把证据放进 `evidence/focus/`（截图/消息/链接）。
4. 如果实验失败：**停**，换问题，不许进入 Phase 1。

## 机器闸门

```bash
node gates/gate-focus.mjs --file FOCUS.md
# 产物：.gates/focus.json（六问是否齐全 + 用户证据是否存在）
```

## 人的闸门

- 你能不看稿说出：谁、什么行为、什么信号放弃吗？
- 那个人真的回应过你吗？（不是“我觉得他会用”）

## 失败分支

- 找不到真实用户 → 先别做产品，先做内容/社群验证。
- 实验失败 → 回 Phase 0 换问题；不许用“再做个功能”掩盖。

## 时间盒

45–90 分钟。**超时不是继续，是缩小问题。**

## 手工版（没装任何 skill 也能做）

拿一张纸，写六问；找一个人发消息；截图存档。
